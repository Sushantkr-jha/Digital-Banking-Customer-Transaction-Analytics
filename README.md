# Digital Banking Customer & Transaction Analytics

## 📊 Project Overview

An end-to-end banking analytics project focused on understanding customer transactions, transaction channels, customer occupations, transaction trends, and key banking insights.

The project transforms raw banking transaction data into meaningful business insights using **SQL, Python, and Tableau**.

## 🛠️ Tools & Technologies

- Python – Data cleaning and exploratory analysis
- SQL – Data querying and business analysis
- Tableau – Interactive dashboards and visualization
- Excel/CSV – Data storage and initial data handling

## 🎯 Business Objectives

- Analyze overall transaction activity
- Compare Credit and Debit transactions
- Analyze transaction performance across banking channels
- Identify transaction trends over time
- Understand customer occupation-wise transaction behavior
- Analyze transaction amounts and customer activity
- Identify useful patterns for banking decision-making

## 📈 Key Insights

- Dataset contains **50,000 transactions**
- Debit transactions account for **38,747 transactions**
- Credit transactions account for **11,253 transactions**
- Total transaction value is approximately **₹14.89 million**
- Branch recorded **17,278 transactions**
- ATM recorded **16,552 transactions**
- Online recorded **16,170 transactions**
- Students recorded the highest transaction count among the occupation groups analyzed

## 📊 Dashboard

The Tableau dashboard presents:

- KPI Overview
- Credit vs Debit Analysis
- Channel Analysis
- Monthly Transaction Trends
- Customer Occupation Analysis
- Customer Risk Analysis
- Geographic/City Analysis
